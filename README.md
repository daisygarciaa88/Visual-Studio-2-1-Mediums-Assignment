# Visual-Studio-2-1-Mediums-Assignment

## prompt A- Charcoal drawing 

Create a charcoal drawing that emphasizes line, texture, contrast, movement, and unity. Use vine charcoal, compressed charcoal, and blending stumps on drawing paper. Apply cross-hatching, smudging, and tonal build-up techniques. The composition should feature a simple pine tree in front of a mountain with a large moon in the sky.

## Prompt B - Linocut Print

Create a linocut print that emphasizes line, texture, contrast, movement, and unity. Use linoleum carving tools, a brayer, and black printing ink on printmaking paper. Apply carving and relief-printing techniques. The composition should feature a simple pine tree in front of a mountain with a large moon in the sky. Use bold carved lines and strong black-and-white contrast.
